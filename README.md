## 🎨 Features

- **Responsive Design** - Works on all devices

## 🚀 Quick Start

1. Open `index.html` in browser
2. Customize your info in HTML
3. Update `profile.jpg` with your photo
4. Change colors in CSS `:root` variables

---

## 🛠️ Tech Stack

- HTML5 - Semantic structure
- CSS3 - Flexbox, Grid, Animations
- JavaScript - Smooth scroll, animations
- Font Awesome 6.5.1 - Icons

---

## 📱 Sections

1. **Header** - Name, title, social links
2. **About** - Bio, profile image, stats
3. **Skills** - 6 skills with progress bars
4. **Experience** - Timeline with 2 entries
5. **Contact** - Email, phone, location
6. **Footer** - Copyright, back to top

---

## 🎯 Customization

**Colors** - Edit in `style.css`:
```css
:root {
    --primary-color: #2c3e50;
    --secondary-color: #3498db;
    --gradient: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
}
```

**Content** - Update in `index.html`:
- Personal info, bio, skills, experience, contact
